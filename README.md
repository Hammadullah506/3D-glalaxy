## ✨ Features

- 🌀 **Interactive 3D Particle Galaxy Engine**
  - Over 35,000 procedurally generated stars with exponential core density and spiral arms.
  - Procedural circular glowing star textures with additive blending.
  - Multi-layer cosmos: galactic disk, singularity core, and deep-space background starfield.
  - Smooth mouse parallax and mobile device gyroscope tilt.

- ⚡ **Hyperspace Warp Jump Mode**
  - Dynamic particle acceleration with camera FOV kick and speed streaks.
  - Synchronized procedural Web Audio API audio sweep.

- 🎛️ **Real-Time Galaxy HUD Controller**
  - **Cosmic Themes**: *Andromeda*, *Supernova*, *Cyber Teal*, *Singularity (Black Hole)*, *Aurora*, and *Gold Dust*.
  - **Live Sliders**: Tweak rotation velocity, particle size, and spiral arm count in real time.
  - **Action Tools**: Trigger hyperspace jump, reset camera perspective, or tune parameters.

- 🎵 **Web Audio API Ambient Synthesizer**
  - 100% procedural ambient cosmic binaural drone and filter sweep (zero external sound files required).
  - Sound visualizer equalizer bars and mute toggle.

- 💼 **Comprehensive Developer Portfolio**
  - **Hero Section**: Kinetic typewriter role rotator and call-to-actions.
  - **About Section**: Developer terminal window (`hammadullah.config.ts`) and key stats.
  - **Projects Showcase**: Filterable project cards (3D/WebGL, Full-Stack, Frontend) with demo and code links.
  - **Skills Matrix**: Categorized tech proficiencies with animated gradient meters.
  - **Interactive Contact**: Working contact transmission simulator and 1-click email copy button with toast feedback.

- 📱 **Fully Responsive & Cross-Browser**
  - Glassmorphism design system (`backdrop-filter: blur()`).
  - Optimized for 60 FPS across desktop, tablet, and mobile browsers.

## 🚀 Quick Start / Local Development

Since this project uses pure standard web technologies and Three.js via CDN, you can run it immediately with zero build steps!

### Option 1: Using Python Local Server
```bash
# Clone the repository
git clone https://github.com/Hammadullah506/3D-glalaxy.git

# Navigate into project directory
cd 3D-glalaxy

# Start local server
python -m http.server 8000
```
Open [http://localhost:8000](http://localhost:8000) in your browser.

### Option 2: Using Node.js `npx serve` or VS Code Live Server
```bash
npx serve .
```

## 🌐 Deploy to GitHub Pages in 30 Seconds

1. Go to your GitHub repository: `https://github.com/Hammadullah506/3D-glalaxy`
2. Click **Settings** (⚙️) tab at the top.
3. In the left sidebar, click **Pages**.
4. Under **Build and deployment > Source**, select **Deploy from a branch**.
5. Under **Branch**, select `main` and `/ (root)`, then click **Save**.
6. In a few seconds, your site will be live at:
   `https://hammadullah506.github.io/3D-glalaxy/`
